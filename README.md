# 高校足球物語

高校足球經營遊戲。玩家擔任青葉高校足球部總教練，在 32 所學校之間招生、訓練、排陣型戰術，從都道府縣聯賽一路打上超級聯賽，並挑戰夏季大會與高校選手權。

整個遊戲是單一 HTML 檔，不需要伺服器或套件，存檔放在瀏覽器的 localStorage。

## 遊玩

直接用瀏覽器開啟 `index.html`。

## 專案結構

| 檔案 | 內容 |
| --- | --- |
| `src/engine.js` | 遊戲邏輯：球員、聯賽與盃賽、訓練、招生、比賽引擎、轉播台詞 |
| `src/kit.js` | 隊服工房：隊徽與球衣設計、其他學校的隊徽 |
| `src/ui.js` | 介面與互動 |
| `src/shell.html` | HTML 外殼與樣式 |
| `build.py` | 把上面四個檔案組成 `index.html` |
| `index.html` | 建置好的遊戲（部署用） |

## 修改後重新建置

```bash
python3 build.py
```

`src/engine.js` 也可以在 Node 裡直接 `require`，方便做平衡模擬。
